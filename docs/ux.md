# UX

O utilizador não precisa conhecer débito/crédito. Trabalha com Venda, Compra, Recebimento, Pagamento, Banco, Caixa, Cliente, Fornecedor e Imposto.

No onboarding responde apenas a perguntas simples sobre actividade, regime fiscal, IVA, moeda, bancos/caixas, inventário, activos, empregados e ano inicial. O sistema sugere o plano de contas e pede confirmação apenas quando houver ambiguidade.
