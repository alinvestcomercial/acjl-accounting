# ACJL Accounting

Sistema contabilístico separado do ACJL Management.

Objectivos: contabilidade para Moçambique, PGC-NIRF/enquadramentos aplicáveis, fiscalidade parametrizável, partidas dobradas, auditoria e integração não destrutiva com o ACJL Management.

Princípio: o utilizador trabalha com vendas, compras, recebimentos e pagamentos; o motor contabilístico trata da classificação e dos lançamentos.

As regras fiscais devem ser validadas contra a legislação oficial vigente antes de produção.
